# Cosa mangiamo, Nonna?

Lunchtime Italian call for Arianna. Nonna phones from her kitchen in Monte di Procida. It is a conversation, not a stack of flashcards.

## The call

1. Nonna speaks a short line. Her voice is a recorded Italian MP3.
2. Early on, that line includes the food or the sentence. Arianna hears it and says it back (speak or tap).
3. Later, Nonna only asks. Arianna says the same words again from memory. A miss shows the phrase; two misses and Nonna says it for her to tap.
4. Nonna answers in Italian, and the call keeps going.

The script, in order:

| | Nonna | Arianna |
| --- | --- | --- |
| Listen | Guarda, la pizza! | La pizza. |
| | Adesso la pasta. | La pasta. |
| | Ecco il pane. | Il pane. |
| | E il formaggio. | Il formaggio. |
| | Guarda la frutta. | La frutta. |
| | Poi la verdura. | La verdura. |
| | Dopo, il gelato. | Il gelato. |
| | Bevi l'acqua. | L'acqua. |
| | Per me, il caffè. | Il caffè. |
| | Ripeti: Nonna, ho fame! | Nonna, ho fame! |
| | Ascolta: Nonna, mi piace la pasta! | Nonna, mi piace la pasta! |
| | Chiedimi così: cosa mangi oggi? | Cosa mangi oggi? |
| Your turn | Te lo ricordi? Cos'è questo? | La pizza. |
| | E questo, tesoro? | La pasta. |
| | E tu, hai fame? | Nonna, ho fame! |
| | La pasta ti piace? Dimmelo. | Nonna, mi piace la pasta! |
| | Adesso chiedimi del pranzo. | Cosa mangi oggi? |
| | Mi saluti? Ciao ciao, buon appetito! | Ciao ciao, Nonna! Buon appetito! |

When she asks what Nonna is eating, Nonna answers “Oggi pasta e fagioli!”

## How to play

Open this folder as a static site (GitHub Pages from the repository root on `main`, or any https host). On a phone, add it to the home screen.

Speaking needs a normal https URL, or `localhost`. A plain `http://` address, or a page opened as a file, will not get the microphone. Tapping always works.

Stars are saved on this phone under `cosa-mangiamo-nonna-v1`, separate from Che tempo fa, Nonna?

## The call

Nonna’s picture is an illustrated portrait: short dark wavy hair, a warm smile, black dress. The same cartoon is the avatar on the home screen, the incoming call, the lunch call, and the goodbye.

Her lines are recorded Italian MP3s — a warm female neural voice, a little slower. The browser’s speech synthesizer is only a backup if a clip fails to load. Your answers use Italian speech recognition (`it-IT`) when you choose Speak it.

## La tavola di Nonna

Each food you get right lands on the table beside her. “Nonna, ho fame!” sets a place. “Cosa mangi oggi?” and she answers “Oggi pasta e fagioli!” — that bowl joins the table too. The last screen is the Sunday lunch table plus your stars.

Eighteen turns, in that order, so the chat stays a chat. First try is 3 stars, second try is 2, and the shown phrase is 1. Three three-star answers in a row light a streak.
